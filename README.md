# TripPlanner

A React-based trip planning application that allows users to search locations, view routes on an interactive map, and simulate travel along the route.

**Live Demo:** https://83c28374.tripplanner-axv.pages.dev

## Features

* Google Sign-In and local authentication
* Location search with autocomplete
* Interactive map with route visualization
* Distance and ETA calculation
* Route simulation with live marker movement
* Responsive trip-planning interface

## Tech Stack

* React.js
* JavaScript
* Redux Toolkit
* React Leaflet
* OpenStreetMap
* Nominatim
* OSRM
* Cloudflare Pages

## Getting Started

```bash
git clone https://github.com/DHANUSH-SELVARAJ/TripPlanner.git
cd TripPlanner
npm install
npm run dev
```

## APIs & Services

* **Nominatim** — location search and geocoding
* **OSRM** — route calculation, distance, and ETA
* **OpenStreetMap** — map data
* **Google** — authentication
